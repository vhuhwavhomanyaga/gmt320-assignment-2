# GMT 320 Assignment 2 Geovisualisation Dashboard

An interactive dashboard that compares the median income and the full-time equivalent (FTE) employment across provinces in South Africa

Built using HTML, CSS, JavaScript and Chart.js

# Dataset

Sourced from Spatial Economic Activity Data South Africa (SEAD-SA)
File used : Province_MedianIncome_Youth_Sex.csv

# How to run locally 

1. Clone the repository
2. Open the folder in VS Code and start the Live Server extension
3. Open 'assignment2.html' in the browser by right clicking and opening with the live server
